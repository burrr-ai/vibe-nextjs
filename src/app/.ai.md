# App Router Reference

## Location
- **Correct**: `/src/app`
- **Wrong**: `/app`

## Route Groups & Page Structure

### Folder Organization

```
src/app/
├── (app)/              # App 서비스 페이지 (AppLayout)
│   ├── page.tsx        # 홈 페이지
│   ├── layout.tsx      # AppLayout (user 인증 + App UI)
│   └── {route}/        # 추가 페이지
│
├── (admin)/            # Admin 서비스 (별도 서비스)
│   └── admin/
│       ├── layout.tsx          # AdminLayout (admin 인증 + Admin UI)
│       ├── (dashboard)/page.tsx # 대시보드
│       ├── login/page.tsx       # 어드민 로그인
│       └── sign-up/page.tsx     # 어드민 회원가입
│
└── layout.tsx          # Root layout (글로벌: StateProvider, OverlayProvider, Toaster)
```

### 라우트 그룹별 역할

**`(app)/` - App 서비스 페이지**
- 메인 애플리케이션 페이지
- AppLayout으로 사용자 인증 + App UI 제공
- 페이지 컴포넌트: `@/services/app/page/` 에서 import

**`(admin)/admin/` - Admin 서비스 페이지**
- 관리자 페이지 (완전히 별도 서비스)
- AdminLayout으로 관리자 인증 + Admin UI 제공
- 페이지 컴포넌트: `@/services/admin/page/` 에서 import

### NEVER create `src/app/page.tsx`
- **WRONG**: `src/app/page.tsx` (BUILD ERROR!)
- **CORRECT**: `src/app/(app)/page.tsx`

### Layout Hierarchy

1. **Root Layout** (`src/app/layout.tsx`)
   - 글로벌: StateProvider, OverlayProvider, Toaster, ReactGrab, SandboxBridge
   - 사용자 인증 없음 (각 서비스 layout에서 처리)
   - `@/lib/layout/root-layout` import

2. **Service Layouts**
   - `src/app/(app)/layout.tsx` → `@/services/app/page/layout` (서버에서 getMe + UserInit)
   - `src/app/(admin)/admin/layout.tsx` → `@/services/admin/page/layout` (서버에서 admin getMe + AdminUserInit)

## Rules

### Imports
- 페이지 컴포넌트: `@/services/{service}/page/` 에서 import
- 레이아웃: 각 서비스의 `page/layout` 에서 import
- 서버 데이터 fetch가 필요하면 app router에서 직접 가능

### Next.js 15
- Always `await params`: `const { id } = await params`
- Don't use 'use client' on app router
- Server Component must async function

### Detail Pages
Two options for passing data to page component:

**Option 1: Pass ID only**
```tsx
import PageComponent from '@/services/app/page/{route}'
export default async function Page({ params }) {
  const { id } = await params
  return <PageComponent id={id} />
}
```

**Option 2: Fetch and pass data (SEO critical)**
```tsx
import { getItem } from '@/services/app/api/{domain}'

export default async function Page({ params }) {
  const { id } = await params
  const data = await getItem(id)
  return <PageComponent initialData={data} />
}
```
